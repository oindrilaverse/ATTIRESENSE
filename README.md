## 🚀 Features

- **Personalized Style Profile:** Quickly establish your style persona by answering 9 quick criteria—including gender, skin tone, body shape, and environment.
- **Intelligent AI Stylist:** Get precise, occasion-specific clothing recommendations generated by Google's Gemini 2.0 Flash model.
- **Smart Outfit Cards:** Conversational output is automatically parsed into clean, scannable visual outfit cards displaying your Top, Bottom, Shoes, and Accessories.
- **Color & Fit Awareness:** Matches outfit color palettes to your exact skin tone while suggesting silhouettes that complement your body type.
- **Privacy-First Storage:** User profiles and API keys are stored entirely locally in your browser (`localStorage`)—no databases, no data harvesting.

## 🏗 Architecture / How it Works

AttireSense leverages a serverless, client-heavy architecture for maximum speed and privacy:

1. **Data Collection:** The user builds a profile via the Onboarding flow. This data (skin tone, climate, style, etc.) is saved to the browser's `localStorage`.
2. **Contextual Prompting:** When the user asks the chat interface a question (e.g., "What should I wear to a tech interview?"), the app retrieves the user's profile and dynamically injects it into a rigorous **System Instruction Prompt**.
3. **AI Generation:** The frontend makes a direct REST API call to `generativelanguage.googleapis.com` utilizing the Gemini 2.0 Flash model.
4. **Custom Parser:** The AI is strictly prompted to use specific emoji tags (like `👕 Top:` and `💡 Why this works:`). A custom JavaScript parser (`renderAIMessage`) intercepts the text stream, extracts these sections using Regex, and constructs highly styled HTML Outfit Cards before rendering them in the chat window.

## 🧠 Technical Highlights & Learnings

Building AttireSense presented unique engineering challenges:

- **Controlling LLM Output Structure:**
  - *Challenge:* Getting an LLM to consistently return data that a frontend can render visually, without the overhead of building a dedicated backend API to enforce JSON schemas.
  - *Solution:* Engineered a bulletproof client-side prompt strategy. By passing a heavily constrained system instruction and leveraging Regex pattern matching (`/👕\s*top\s*:/i`), I built a custom parser that gracefully falls back to standard markdown if the AI ever hallucinates, ensuring the UI never breaks.
- **State Management in Vanilla JS:**
  - *Challenge:* Sharing state (Profile Data, API Keys, Chat History) seamlessly across multiple static HTML pages (`index.html`, `onboarding.html`, `chat.html`).
  - *Solution:* Developed a lightweight, modular wrapper around the `localStorage` API in `app.js`. This allowed for persistent, cross-page state updates without the bloat of React/Redux, keeping the app blazingly fast and simple.
